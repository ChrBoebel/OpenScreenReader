# Getting help

Saywing is an open-source project maintained in spare time. There is no signed public release yet; see the [README](README.md#install) for the current status.

- **Questions, ideas and setup help:** use [GitHub Discussions](https://github.com/ChrBoebel/saywing/discussions).
- **Bugs:** open a [bug report](https://github.com/ChrBoebel/saywing/issues/new?template=bug_report.yml).
- **Accessibility barriers** in Saywing's own interface: use the [accessibility form](https://github.com/ChrBoebel/saywing/issues/new?template=accessibility.yml).
- **Security vulnerabilities:** report them privately as described in [SECURITY.md](SECURITY.md), never in public issues.

Please never post private screen text, dictated text, meeting transcripts or audio. Use public or made-up examples.

Saywing reads selected regions of the screen aloud and offers local dictation. It is not a screen reader in the VoiceOver sense and does not replace VoiceOver; for full non-visual operation of macOS, use VoiceOver.
